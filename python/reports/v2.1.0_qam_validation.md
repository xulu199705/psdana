## 实现与接口

新增 `python/psd/qam/` 的 config、constellation、rrc、timing、carrier、metrics、receiver、plotting。
`QAMConfig` 固定默认数学参数；`analyze_qam` 返回 `QAMResult`；`recover_symbols` 保留全量有效符号供诊断。
`psd/analysis.py:analyze_iq` 组合 PSD、可选 Power 和可选 QAM，CSV 只读取一次。
`psd/iqio.py` 独立解码 packed64；真实采样直接复用既有 csvio，无需修补数据。
`qam_gen.py`、`qam_reference.py`、`generate_qam_golden.py` 提供可重复生成与独立真值验证。
五个 `test_qam_*.py` 模块覆盖算法、输入、真实采样、绘图和 Golden。

接收链仅使用匹配滤波、定时同步、CFO 与一个复数标量，无多抽头均衡、DFE、CMA/LMS 或 image cancellation。
匹配滤波/插值只执行一次；定时搜索复用插值数组，CFO 使用中心子集，正式误差统计使用全部分析符号。
API 的必选/可选、默认值、结果字段和多个示例已补充至 [Python API](../API.md) 和 [Go API](../../go/API.md)。

## 指标数学契约

全部正式指标使用同一组 y/d，e=y-d，D=sum(|d|²)：

```text
EVM=100*sqrt(sum(|e|²)/D)
radial=real(e*conj(d))/|d|; tangential=imag(e*conj(d))/|d|
Amplitude=100*sqrt(sum(radial²)/D)
Phase=100*sqrt(sum(tangential²)/D)
EVM²=Amplitude²+Phase²
AngleRMS=sqrt(mean((angle(y*conj(d))*180/pi)²))
```

Phase(%) 是切向误差，AngleRMS 是 principal-value 角度 RMS，二者物理量不同。
gain、固定相位和 CFO 校正量作为诊断保留，不解释为校正后误差或绝对 ADC 增益。
QAM 的理想星座平均功率1不改变 PSD Full Scale（complex1、real.5）或频段积分定义。
标准 JSON 禁止 NaN/Infinity，未估计 CFO=None/null，复数诊断为 real/imag。

## 限制与后续移植

- 实际 QAM 捕获与用户参考一致，无 BLOCKED 或 FAILED 验收项；没有 TX truth 的真实数据不提供 Data-Aided qualification。
- 当前正式接收验收针对64QAM；16/256QAM的星座/判决/标量几何测试通过，尚无真实采样资格验证。
- CFO为有界盲搜索，超范围或局部最小可能不触发边界；无 tracking loop、采样时钟偏差跟踪或 equalizer。
- 有限记录均值估计可能移除真实符号样本均值；finite-span RRC、window/定时格点与未知失真影响残余 EVM。
- 接收机拒绝明显不可靠的输出，但 occupancy/EVM 门限不是任意信号的锁定证明。
- 未执行性能 benchmark、板级测量或本版新的安全/race扫描；Go 仅运行现有回归，未声称这些检查通过。
- Go QAM 移植应先复现 unit-energy RRC、SciPy polyphase/Kaiser边界与幅度、same卷积对齐、
  trim/中心截取及相位网格，再复现 slicer索引/90°模糊、固定迭代scalar与粗细CFO候选顺序。
  对相同评分的确定性选择、完整有效符号统计、uniform绘图抽样和null语义应保持一致。
  保留独立解析测试与TX真值验证，不能仅用自生成Golden证明数学正确性。

插值/卷积 API 语义参考 SciPy 官方 [resample_poly](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample_poly.html)
和 [fftconvolve](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.fftconvolve.html)。
