## 2. PowerResult API 与数学定义

- Python：`analyze_band_power(result, freq_left_hz, freq_right_hz) -> PowerResult`。
- Go：`AnalyzeBandPower(result PSDResult, left, right float64) (PowerResult, error)`。
- 只消费已有 PSDResult，不读取 CSV、不执行 FFT、不修改输入、不依赖绘图。
- PowerResult 字段：freq_left_hz、freq_right_hz、is_point、peak_frequency_hz、peak_power_dbfs、average_power_dbfs、band_power_linear、contributing_bins。
- band_power_linear 为绝对输入单位平方；点频模式时为所选 bin 的 RBW 校准功率。
- contributing_bins 是与频段存在正宽度重叠的 distinct signed bin 数；零功率 bin 也计数，点频为 1。

```text
Peak = max(Pxx[k]*ENBW) over bins with positive interval overlap
Band = sum(Pxx[k]*overlap_width[k])
Peak_dBFS = 10*log10(Peak/P_FS)
Average_dBFS = 10*log10(Band/P_FS)
```

Average 表示时间平均带内信号功率估计，绝不是 mean(PSD)、mean(dB) 或 sum(RBW)。
Pxx 保持输入单位平方/Hz，PSD density 的 dB 单位为 dBFS/Hz，以上两种功率单位为 dBFS。

## 3. 频率区间、点频与 Full Scale

严格要求有限 `-fs/2 <= left <= right <= fs/2`，越界一 ULP 也报错，不使用固定 MHz epsilon。
非零频段为 `[left,right)`；centered bin 单元宽度 df=fs/N，超出 Nyquist 边界的部分周期性折回。
全带时每个 signed bin 总宽度恰为 df，积分在舍入容差内等于原 integrated_power。
网格由 bin 序号和 df 建立；轴一致性检查只容许与 float64 精度成比例的舍入误差。
返回实际 bin 中心，部分重叠/周期折回时该中心可以位于请求范围之外。

点频选择最近的网格中心；等距或同功率选择较低频率。Peak=Average=该 bin RBW 功率。
`+fs/2` 点频特例选择严格小于 +fs/2 的最高 signed bin；不添加虚构 +fs/2 bin。
偶数 Nyquist 中心为 -fs/2，其单元在正负边界各承担一半宽度。

complex P_FS=1；real P_FS=.5。实数单边 PSD 的内部 bin 正负各一半，DC/偶数 Nyquist 唯一，奇数末正 bin 仍拆分。
因此满幅实数单音单侧 Peak 约 -3.0103 dBFS，全带 Average 约 0 dBFS，参考定义没有改变。
全零或精确零 PSD 区域的峰值频率为 None/nil，两个 dB 值为 -Inf，标准 JSON 编码为 null。
没有噪声门限或 0 dBFS 裁剪；有限的极小 FFT 残差仍作为非零估计保留。

## 5. Python-Go 误差

比较脚本既将 Go 的完全相同 PSD 数组交给 Python，又比较两端独立 FFT 得到的 PSD。
线性判据为 abs(error)<=1e-18+2e-11*abs(expected)，显著功率阈值 1e-18，dB 绝对容差 1e-7。
共享 PSD 路径始终比较 dB/频率；独立 PSD 路径的深残差区域只用线性功率验收，不将 FFT 消去残差放大成 dB 判据。
边界、点频标志、参与 bin 数保持精确一致；频率返回有 float64 舍入容差。

| 字段 | 共享 PSD max abs | 独立 PSD max abs |
|---|---:|---:|
| Peak Power dBFS | 1.13686838e-13 dB | 1.31350930e-10 dB |
| Average Power dBFS | 1.13686838e-13 dB | 1.31350930e-10 dB |
| band_power_linear | 1.77635684e-15 | 8.88178420e-16 |
| peak_frequency_hz | 0 Hz | 0 Hz（参与比较的结果） |

所有参与验收的结果均未超容差。逐案例/字段详情见 [功率比较数据](v2.0.1_power_comparison.json)。
原 Golden 最大 PSD 绝对误差=2.96461532e-21，显著 dB 最大误差=7.04858394e-9 dB，保持原容差通过。
原 20 组 PSD 直接比较最大线性 PSD 绝对误差=2.03287907e-20，显著 RBW 最大误差=3.24718030e-12 dB。

## 7. 安全、兼容性与限制

- 原 data/ 的 30 个文件及 Python csvio/plotting 两个模块逐字节与 V2.0.0 一致，go.mod/go.sum 未改变。
- 新模块验证维度、空数组、有限非负功率和一致频率轴；测试确认无输入修改和 bin 越界。
- 绝对本机路径、私人邮箱、凭据模式、私钥的可提交文件扫描无发现；工具、临时输入和原始执行日志保持忽略。
- govulncheck 源码调用链扫描已实际运行，采用官方漏洞数据库；结果仅表示当前扫描未发现已知可达漏洞，不替代完整安全审计。
- race detector 尚未执行，需具备兼容 C 工具链后补测。
- float64 下溢可成为零；极限动态范围不保证高相对精度，溢出中间值明确拒绝，不采用隐式幅度缩放。
- 分辨率/窗泄漏决定窄带估计；未做任意频率插值、物理单音检测或残差门限。不存在已发现但未修复的正常输入功能失败。
- 本次未复测性能 Benchmark；Phase 2 表格仍是 V2.0.0 的历史实测，不据此宣称 V2.0.1 性能变化。
